# 오피스 로얄 기획 정리

claude.ai에서 기획·프로토타입을 만든 대화(2026-10)를 정리한 문서. 확정된 것, 지금 코드에 들어간 수치, 보류한 아이디어를 함께 적는다. 세부 수치는 코드가 기준이고, 이 문서는 "왜 그렇게 정했는지"를 남기는 용도다.

## 1. 한 줄 콘셉트

회사 건물에서 벌어지는 배틀로얄. 고과가 체력, 서류가 무기. 1층부터 층이 차례로 폐쇄되고, 최후의 1인이 7층 대표실에 들어간다. PC·모바일 실시간, 봇 모드 지원. "가벼운 배그 + 직장인 블랙코미디".

## 2. 핵심 규칙 (현재 구현)

- 20명(나 + 봇 19) 시작, 고과 50. 0이 되면 권고사직(탈락).
- 직급은 **최고 고과(peak)** 기준: 인턴 → 대리 60 → 팀장 75 → 임원 90.
  - 직급별 공격력 배수: 인턴 1 / 대리 1.3 / 팀장 1.6 / 임원 2.
  - 팀장이 되면 팀을 고른다: 인사팀장(한 번 인턴으로 재입사), 개발팀장(업무 2배 속도·사원증 태그 0.3초), 마케팅팀장(전단지 광역 공격, 쿨 12초), 디자인팀장(4초 위장, 쿨 20초).
  - 임원은 부장님에게 인사할 필요가 없다. 부장님이 먼저 "상무님 오셨습니까!"(+1). 부장님 앞에서 던지거나 뛰어도 안 걸린다. 대표님은 예외.
- 처치 보상: 막타 기준(탈락 직전 4초 안에 맞힘) 고과 +10, 나보다 직급 높은 사람이면 +6 추가.
- 피해: 서류 5, 스테이플러/전단지 3, 서류 뭉치 폭발 7, 식은 커피 함정 5(뛰다 밟으면 9 + 기절). 모두 직급 배수 적용.
- 층: 로비(1F)~6F 임원층, 7F 대표실(목표). 동시에 열리는 층은 3개(WIN=3), 40초마다 맨 아래층 폐쇄, 10초 전 경고, 5초 전 화면 카운트다운. 폐쇄된 층은 빨간 효과만(줄무늬 없음).
- 층 이동: 계단(채널링 중 맞으면 취소) / 엘리베이터(소방훈련 때 정지).
- 업무: 책상 보고서 +8, 복사 +6, 출력물 배달 +12, 회의 참석 +10, 서버 재부팅 +15, 출입증 발급 +8, 방문객 응대 +8. 층당 동시 업무 3~5개. 폐쇄 직전 층은 보상 2배.
- 휴식: 내 자리에 앉으면 회복, 화장실은 숨을 수 있지만 오래 있으면 불이익.
- 한 판 길이 목표: 약 4~5분 (`node tools/headless.mjs`로 확인).

## 3. 아이템 (색깔 빛 = 종류)

- 줍는 순간 바로 효과: 커피 +12, 배달 음식 +15(옥상 보급), 결재 도장(3번 막기), 임원 인맥(10초 상사 감지 면제), 야근 식권(8초 속도 +45%).
- 한 개만 들고 다니다 F/우클릭(폰: 칸 탭)으로 사용: 스테이플러(15발 연사), 서류 뭉치(광역), 식은 커피(바닥 함정), 법카(주변 3초 기절).
- 이미 하나 들고 있으면 다른 공격 아이템은 안 주워진다. 버리기 없음.
- 감사 이벤트 중 같은 층에서 아이템 쓰면 압수 -5.
- 결재 서류는 별도 주머니(부장님께 결재 올리기 +8).

## 4. NPC

| NPC | 동작 |
|---|---|
| 부장님 (층당 2) | 노란 부채꼴 시야. 시야에 들어가면 먼저 인사(E, +3). 늦으면 호출 3지선다(인사/보고/바쁜 척). 앞에서 던지면 현장 적발 -10, 뛰면 -4. 점심·막판엔 자리 비움 |
| 대표님 (이벤트) | 10초 예고 후 랜덤 층 등장. 인사 +10, 놓치면 -8, 앞에서 던지면 고과 반토막 |
| 청소 아주머니 | 젖은 바닥(뛰면 미끄러짐 -4). 인사하면 +1과 8초간 층 인원 위치 정보 |
| 옆팀 팀장 (2~5F) | 시야에 걸리면 잡담으로 3초 묶임 |
| 신입 인턴 (2F~) | 근처 사람에게 달려와 질문 공세: 5초 느려짐, E로 답하면 +2 |
| 택배 기사 (2F~) | 가끔 엘리베이터로 등장해 24초간 돌아다니며 아이템 상자 투하 |
| 커피 카트 (전 층) | 천천히 이동, 반경 안에서 고과 회복(70까지만). 싸움터가 되기 쉬움 |
| 문 방문객 | 청소(+1) / 택배 / 영업사원(-1) / 면접자. 문을 열어줄지 판단 |

## 5. 이벤트

대표님 방문, 정전(10초, 부장님도 못 봄), 생일 케이크(+8), 소방훈련(엘리베이터 15초 정지), 감사(아이템 금지 20초), 이달의 우수사원(1위 위치 공개), 그리고 점심.

**점심시간 "흡연 동맹 난투전"** (약 100초 시점, 30초)
- 종이 울리면 엘리베이터/계단이 옥상으로. 계단 = 왼쪽 문, 엘리베이터 = 오른쪽 문.
- 같은 문으로 나온 사람끼리 임시 흡연 동맹(서로 공격 안 됨), 반대편 동맹과 난투.
- 하늘에서 보급품(배달 음식 등) 낙하.
- 끝나면 원래 있던 층으로 복귀하고, 점심 전보다 고과가 떨어졌으면 점심 전 고과로 되돌린다.
- 부장님은 식사 중이라 업무·폐쇄 일시정지.

## 6. 조작 (확정)

- PC: WASD 이동, Shift 달리기(부장님 앞·젖은 바닥 페널티), Space/좌클릭 던지기(마우스 방향), E 상호작용(인사·업무·문·제출 전부), F/우클릭 공격 아이템, Q 팀장 스킬, Tab 지도, 1~3 호출 답변.
- 모바일: 왼쪽 드래그 조이스틱(끝까지 밀면 달리기), 던지기·상호작용·스킬 버튼, 아이템 칸 탭.
- 과정 메모: 방향키+QWER, 1~4 아이템 칸 등 여러 안을 거쳐 지금 구성으로 정착. 키가 많으면 불편하다는 피드백이 반복됨 → 상호작용은 E 하나로 몰기.

## 7. 시점·아트 결정 이력

- 2D 탑다운 프로토 → 3D 비교 테스트(쿼터뷰 / 높은 3인칭 / 3인칭 어깨뷰) → **쿼터뷰(롤 느낌) 확정**.
  - 쿼터뷰: 깔끔하고 한눈에 보이고 만들기 쉬움. 시야 안개(벽 너머 어둡게)로 긴장감 보완.
  - 높은 3인칭: 별로라는 평가로 탈락.
- 아트 시안 A(귀여운 2D)~E(픽셀) 5종 모두 "맘에 안 듦". 쿼터뷰 화면 기준으로 **아트 방향 다시 잡아야 함**. 현재는 콩알 캐릭터 + 파스텔 기본 도형.

## 8. 보류·미정 아이디어

- **3인칭 어깨뷰 모드**: 긴장감은 압도적, 배그 느낌. 단점은 어지러움(카메라 3.4m→4.4m, 화각 68, 부드러운 추적으로 개선했지만 미확정). 특별 모드나 이벤트 맵용으로 검토 가치 있음. 프로토: `prototypes/camera-compare.html`(쿼터뷰/높은 3인칭/3인칭 비교판, 단일 파일).
- 쿼터뷰에 3인칭 긴장감 살리기: 시야 안개 더 좁히기, 부장님 접근 시 발소리 표시·카메라 살짝 당기기, 파티션 뒤 웅크리기.
- 점심 이벤트 확장: 옥상 **경매**(보급품을 고과로 입찰), 동맹 배신 장치.
- 1인칭: 캐릭터·개그가 안 보여 비추로 정리.
- 식은 커피·법카를 즉시 사용으로 옮길지 미정.
- 임원 도달자가 판당 5~7명으로 많은 편. 2026-10 측정: 고과 상승의 51%가 업무, 처치는 1.4%라 처치 보상 하향은 효과 없음(5.7→6.5명). 임원은 결승권 생존자(2~6등의 50~70%)에 몰림. 대리·팀장 때 최고 고과 상승분만 깎으면(0.5/0.25배) 3.3명까지 줄었음 → 결정 대기.
- 한글 도트/게임 폰트 결정(갈무리 등).
- 제목 미정. 후보: 서류전쟁(추천), 권고사직, 승진 아니면 퇴사, 대표실까지, 낙하산, 고과 로얄, 사내정치, 오피스 로얄(현재).

## 9. 로드맵

1. 싱글(봇) 웹게임. Cloudflare Pages 배포.
2. 멀티 1단계 (2026-10 구현, https://office-royale.bb-dochi.workers.dev 에 배포): 친구 방(초대 코드, 최대 8명) + 봇 채우기. 방장이 시작, 중간에 나가면 봇이 이어받음, 끝나면 8초 뒤 대기실. 로컬은 `node tools/dev-server.mjs`. Cloudflare Workers + Durable Objects(무료 플랜은 SQLite 백엔드만, 하루 요청 한도 있음 → 입력만 보내고 서버가 `public/js/sim`을 돌려 초당 ~10회 상태 전송, WebSocket Hibernation 사용).
3. 아트 방향 재설정 → 캐릭터·사무실 에셋 교체.
4. 사운드, 튜토리얼, 결과 화면 공유.

## 10. 함께 일하는 방식 (사용자 성향)

- 한국어, 짧고 캐주얼한 대화. iOS·PC 둘 다 사용.
- 직접 플레이해 보고 피드백 주는 스타일 → 바뀐 걸 바로 플레이할 수 있게 빠르게 반영하는 걸 선호.
- 선택지가 갈리면 장단점 짧게 + 추천 하나를 원함.
