## 2. 핵심 규칙

### 2-1. 고과·처치

**목적**: 고과 = 체력 = 점수. 0이 되면 탈락.

**규칙**
1. 시작 고과 50.
2. 고과 0 → 권고사직(탈락).
3. 처치 보상은 막타 기준(탈락 직전 4초 안에 맞힘).

**수치**

| 항목 | 값 | 비고 |
|---|---|---|
| 시작 인원 | 20명 (나 + 봇 19) | |
| 시작 고과 | 50 | |
| 처치 보상 | +10 | 막타 기준 |
| 상위 직급 처치 추가 | +6 | 나보다 직급 높은 사람 처치 시 |

**예외·주의**
- 플레이어 자동 회복은 모든 난이도에서 없음.
- 봇은 6초 안 맞으면 고과 60까지 자동 회복(항상). 상세는 4장.
- 고과 100 상한. 상한 문제와 승진 계산은 2-2.

### 2-2. 직급·승진

**목적**: 최고 고과(peak)로 직급이 오르고 공격력이 커지는 성장 축.

**규칙**
1. 직급은 **최고 고과(peak)** 기준으로 오른다.
2. 직급 5단계: 인턴 → 사원 → 대리 → 팀장 → 임원. 부장은 NPC로만 둔다(플레이어 직급과 헷갈림).
3. 승진 진행에는 새로 얻은 고과 중 일부만 반영(고과 자체는 그대로).
4. 커피·정수기·커피 카트 같은 회복은 승진에 안 쳐줌. 화면엔 "회복 +n"으로 표시.
5. 승진은 100으로 자르기 전 상승분으로 계산(고과 100에 붙어도 업무로 승진 진행).
6. HUD 승진 줄: "팀장까지 실적 +N". N = 앞으로 업무로 벌어야 하는 고과(최고점까지 되찾을 양 + 남은 진행 ÷ 비율). 일하면 항상 줄어듦.
7. 임원은 부장님에게 인사할 필요 없음. 부장님이 먼저 "상무님 오셨습니까!"(+1). 부장님 앞에서 던지거나 뛰어도 안 걸림. 대표님은 예외.
8. 임원이 되면 일반 부장님 시야 부채꼴은 안 그림. 전무님·대표님 시야는 그대로.

**수치**

| 직급 | 승진 커트 (peak) | 공격력 배수 | 승진 진행 반영 비율 |
|---|---|---|---|
| 인턴 | - | 1 | - |
| 사원 | 55 | (미기재) | 50% |
| 대리 | 65 | 1.3 | 17% |
| 팀장 | 80 | 1.6 | 14% |
| 임원 | 95 | 2 | - |

- 직급별 공격력 배수는 모든 피해에 적용(3-1).
- 이름표 직급 칩: 회색(인턴) → 직급이 오를수록 진해지는 파랑 한 계열(사원·대리·팀장·임원), 흰 글자, 장식 없음, 팀 색 안 씀. 내 이름표는 검정 바탕 + 흰 테두리, 발밑 링 흰색.

**승진 속도 결과** (headless)

| 시점 | 대리 | 팀장 | 임원 |
|---|---|---|---|
| 현재 비율 (사원 50 / 대리 17 / 팀장 14) 20판 | - | 3.9명 | 1.0명 |
| 1차 조정 (50 / 30 / 70, 커트 65·80·95) | 판당 평균 70초 | 약 3.6명 (3분쯤) | 0.7명 (3분 40초쯤) |
| 그 전 | - | 6.6명 | 5.6명 |

**예외·주의**
- 같은 고과 상한 문제로 임원이 판당 5명까지 늘었던 것을 비율 하향으로 정리.

**기획 의도 / 결정 기록**
- 결정(2026-10): 비율 사원 50% · 대리 30% · 팀장 70%, 커트 65·80·95. / 이유: 로비 커피 한 잔에 바로 사원이 되던 것, 임원 과다 방지.
- 결정(2026-10): 승진을 100으로 자르기 전 상승분으로 계산하고 비율을 **사원 50 · 대리 17 · 팀장 14**로 낮춤. / 이유: 고과가 100에 붙으면 업무를 해도 승진이 멈췄음(대리 65→100까지 올려도 peak 76에서 정지, 맞아야 다시 진행). 고치니 꽉 찬 상태에서도 승진이 쌓여 임원이 판당 5명까지 늘었음.
- 인턴 → 대리 60 → 팀장 75 → 임원 90은 옛 커트(현재는 위 표).

### 2-3. 팀 발령

**목적**: 인턴 때 한 플레이가 팀과 혜택이 되게 해 플레이 스타일에 보상을 줌.

**규칙**
1. **팀 = 인턴 때 많이 한 일로, 사원 승진 순간 발령**(2026-10 확정).
2. 인턴 동안 한 일을 팀별로 센다.
3. 사원이 되는 순간 1등 팀으로 발령. 모두 0이면 랜덤.
4. 인턴 동안 지도 아래에 "부서 발령 · 사원 승진 때 · → 개발팀 / 업무 n · 명중 n · 응대 n"으로 실시간 미리보기 (PC만, 모바일은 목록 칸이 작아 `isTouch`면 안 띄움).
5. 사원 승진 쪽지와 발령은 한 장으로 5초.
6. 팀은 색 없이 캐릭터 소품으로 표시.
7. 발령 팝업·알림에 인턴 때 실적(이유)은 안 쓰고 팀 이름과 혜택만.

**수치**

| 팀 | 인턴 때 세는 행동 | 가중치 | 소품 |
|---|---|---|---|
| 개발 | 업무(노란 원·배달·자리 근무) | 1 | 노트북 |
| 마케팅 | 서류 명중 | 0.5 | 메가폰 |
| 인사 | 부장님·동료 응대(인사·호출 정답·결재·부탁·신입 챙기기) | 1.5 | 클립보드 |

| 직급 | 팀 혜택 |
|---|---|
| 인턴·사원 | 없음 |
| 대리 | 업무 1.5배 / 사거리 +12% / 받는 피해 -5% |
| 팀장 | 업무 2배 / 사거리 +25% / 받는 피해 -10% + 팀 스킬 Q |
| 임원 | 스킬 강화 (쿨 ×0.6 + 효과 강화) |

**예외·주의**
- 디자인팀은 개발과 구분되는 기준이 마땅치 않아 TEAMS에서 뺌. 데이터는 `BRANCH`에 남김.

**기획 의도 / 결정 기록**
- 결정(2026-10): 인사팀 효과를 '탈락 시 1회 재입사'에서 방어력으로 변경. / 이유: 재입사가 체감이 안 됨.
- 결정(2026-10): 팀 고르기를 **첫 실적 발령**으로 확정. / 이유: 아래 시행착오 참고.
- 디자인팀 복귀 조건: 확실한 플레이 축이 생길 때. 그때 Q는 "목업 더미" 후보.

### 2-4. 층·폐쇄

**목적**: 시간이 지날수록 싸움터를 좁혀 판을 끝낸다.

**규칙**
1. 로비(1F) ~ 6F 임원층, 7F 대표실(목표).
2. 동시에 열리는 층은 3개.
3. 40초마다 맨 아래층 폐쇄. 10초 전 경고, 5초 전 화면 카운트다운.
4. 폐쇄된 층은 빨간 효과만(줄무늬 없음).
5. 층 이동: 계단(채널링 중 맞으면 취소) / 엘리베이터(소방훈련 때 정지).
6. 곧 폐쇄될 층의 업무는 보상 2배.

**수치**

| 항목 | 값 |
|---|---|
| 동시에 열리는 층 (`WIN`) | 3 |
| 폐쇄 주기 | 40초 |
| 경고 | 10초 전 / 5초 전 카운트다운 |
| 폐쇄 직전 층 업무 보상 | 2배 |

### 2-5. 업무

**목적**: 고과를 올리는 기본 수단. 층 이동·경쟁을 만든다.

**규칙**
1. 업무는 **먼저 시작한 사람 것**: 그 사람만 게이지를 채우고 제출.
2. 2.5초 넘게 자리를 비우거나 탈락하면 0부터 다시 빈 업무가 됨 (남이 채운 걸 E로 가로채기 방지).
3. 로비 업무는 제출 뒤 15초 동안 그 자리가 비어 있음.
4. 업무 제출: 다 되면 1초 뒤 자동 제출, E는 즉시 제출. 봇은 0.25~0.85초 반응 → 경쟁.
5. 층당 동시 업무 5개 (마지막 층 6개, 새로 열린 꼭대기 층은 1~2개). 2026-10-30 4개→5개: 같은 자리 5초 쉼이 생겨서 여분 자리를 둠.

**수치**

| 업무 | 고과 |
|---|---|
| 책상 보고서 | +8 |
| 복사 | +6 |
| 출력물 배달 | +12 |
| 회의 참석 | +10 |
| 서버 재부팅 | +15 |
| 출입증 발급 | +8 |
| 방문객 응대 | +8 |

**위층 업무 독점 방지** (2026-10 v2): 맨 위 열린 층의 동시 업무 수

| 시점 | 맨 위 열린 층 | 다른 층 | 결승층 |
|---|---|---|---|
| 초반 (폐쇄 0~1회) | 1개 | 4개 | 5개 |
| 그 뒤 | 2개 | 4개 | 5개 |

**기획 의도 / 결정 기록**
- 결정(2026-10 v2): 맨 위 열린 층 업무 수를 줄임. / 이유: 맨 위층에 혼자 올라가 업무를 독차지하던 것 방지. 태만 감점을 더 세게 하는 안보다 이쪽을 택함(사용자).
- 측정(2026-10): 고과 상승의 51%가 업무, 처치는 1.4%. 처치 보상 하향은 효과 없음(5.7→6.5명, 13장).

### 2-6. 업무 태만 (존버 방지)

**목적**: 위층에서 가만히 버티는 플레이 방지.

**규칙**
1. 45초 동안 실적도 공격도 없으면 고과가 초당 0.35씩 샘.
2. 30초부터 경고 칩.
3. 제외: 점심·인사 시즌·옥상·자리 근무 중.
4. 쉬움: 감점 없음. 보통·어려움만 적용 (`idle`, 4장).

**수치**

| 항목 | 값 |
|---|---|
| 감점 시작 | 45초 무실적·무공격 |
| 감점량 | 초당 0.35 |
| 경고 | 30초부터 칩 |

### 2-7. 휴식 (화장실)

**규칙**
1. 화장실은 숨을 수 있지만 오래 있으면 불이익 (10초 넘게 있으면 감소).
2. 문이 닫혀 있으면 안팎으로 시야가 막힘.
3. 안에 있으면 공격 대상에서 빠짐.
4. 변기에 앉아 하는 미니게임은 7-2 화캉스.

### 4-2. 규칙

**회피**
- 날아오는 서류가 몸에 맞을 줄이면 옆으로 한 걸음(서류 하나당 한 번 판정, 한 걸음 옆으로 0.3초).
- 확률 = (`dodge` + 최근 4초 안에 맞았으면 `guard`) × (0.4 + 0.6 × 무빙 실력).
- 무빙 실력(0~1): 높으면 전속으로 자주 방향을 바꿔 움직이고, 낮으면(허당) 느리게 한쪽으로 오래 가고 가끔 멈춤.

**예측 사격**
- 상대의 **부드럽게 평균 낸 속도**(`svx/svy`, `drive()`에서 초당 8배 비율로 갱신)로 앞서 쏨.
- 벽 뒤를 겨누는 예측은 안 함.

**선공** (`DIFF.hunt`, 2026-10)
- 봇 중 일부(보통 20%, 어려움 **40%**)가 각각 130px / 180px 안에 사람이 보이면 성격과 상관없이 먼저 공격.
- 한 사람에게 동시에 먼저 달려드는 봇은 보통 1명, 어려움 2명. 쉬움은 맞아야 반격.
- 부장님 앞에서 안 던지는 건 그대로. 봇끼리는 기존 성격대로.

**마지막 층 수색 (존버 방지)**
- 마지막 층만 남으면 봇 일부가 '수색조'가 되어 숨은 사람도 가장 가까운 사람에게 걸어가 찾아냄(보이면 바로 공격).
- 사람만 찾고 봇끼리는 기존대로. 비율·시작 시점은 4-1 표 `seek` / `seekAfter`.

**자동 회복**: 플레이어는 모든 난이도에서 없음(`regen:false`). 봇은 6초 안 맞으면 고과 60까지 항상 회복.

> **업데이트 대상 섹션** — 수치가 바뀌면 이 절의 표만 고치면 된다.

코드: `WC`, `wcGain`, `startWc`, `wcStep`, `wcLeave` (`sim/50-actions.js`), 폰 화면 `phoneHud` (`client/30-hud.js`)

**목적**: 화장실 변기에 앉아 폰으로 코인 차트 한 판. 언제 팔지 정하는 타이밍·운 게임 (자리 근무는 정확성 게임).

**규칙**
1. 화장실 안 변기(층마다 1개)에 앉아 E → 폰 코인 차트 시작.
2. ×2에서 시작. 판마다 **상승장 또는 하락장**(반반)으로 시작하고, 중간에 바뀔 수 있음.
3. 가끔 **출렁**: 1초 안쪽 동안 차트가 거의 멈춘 채 떨리다가(폰에 "출렁출렁… 곧 터진다!") **순식간에 튐**.
   - **떡상**: 배율 ×1.5~2배로 점프
   - **떡락**: 배율 ×0.4~0.6배로 점프 (판은 계속)
   - **상장폐지**: 판 즉시 끝, 고과 -4
4. 아무 때나 E로 팔면 그때 배율로 정산. 8초면 자동으로 팜.
5. 한 판 후 쿨타임(결과 전에 폰을 내려놓거나 결과 직후 일어나도 똑같이 돌아요). 지금은 사람만 사용(봇 X).
6. 출렁의 결과(떡상/떡락/상장폐지)는 서버만 앎. 클라엔 지금 배율과 "출렁 중"만 보냄.

### 10-2. 모바일 조작

**규칙**
1. 왼쪽 드래그 조이스틱(끝까지 밀면 달리기) + 큰 버튼 둘(서류 투척·상호작용)이 전부.
2. 자리 근무 중엔 화면 방향 버튼.
3. 그 위 오른쪽에 PC 키 안내와 같은 모양의 칩이 **쓸 수 있을 때만** 뜨고, 누르면 실행:
   - ▼ 아래층 (계단·엘리베이터 위, 상호작용이 이미 ▼면 숨김).
   - 팀 스킬 (팀장부터, 쿨타임 막대).
4. 아이템 칸은 폰에서 없앰: 공격 아이템은 서류 투척 버튼 글자·색이 바뀌어 보이고, 방어(결재 도장·이어폰)는 효과 줄에 표시.
5. 가로 화면에선 칩이 한 줄로 눕고 부서 발령 패널은 사원증 밑으로.
6. 모바일 달리기: 손가락이 시작점에서 92px(노란 점선) 넘게 멀어져야 달림, 12px 여유로 깜빡임 방지.
7. 조이스틱은 지금 방식(왼쪽 아무 데나) 유지.
8. 팀 발령 미리보기 목록(`questList`)은 PC에서만 (2-3).

**버튼 모양**
- 흰 종이에 검은 테두리 → 사원증·지도 패널과 같은 어두운 유리 + 밝은 테두리로 통일.
- 서류 투척: 바깥 고리가 쿨타임 동안 다시 차오르고, 공격 아이템을 들면 고리·빛이 아이템 색.
- 상호작용: 할 일 있으면 노랑, 제출 가능하면 초록, 할 게 없으면 흐리게(점선 없음). 누르면 살짝 작아짐.

**좁은 폰 (480px 이하)**: 아이템 두 칸을 왼쪽에 세로로 쌓고, 상호작용 버튼이 그 사이 공간에서 두 줄로 줄바꿈("담배 피우기 (연막)" 같은 긴 문구가 잘리던 것). 화면 가장자리 이름표·말풍선·작업 꼬리표는 화면 안으로 밀어 넣음. 한글은 단어 단위 줄바꿈(`keep-all`).

**모바일 점검(375·320px, 가로 812×375) 수정**: 부서 선택 상자가 화면보다 넓던 것, 320px에서 지도 제목·부서 발령 패널·주간 랭킹 1등 이름 잘림, 가로 화면에서 지도가 오른쪽 밖으로 나가던 것.

**기획 의도 / 결정 기록**
- 과정: 처음엔 칩 셋(▼·스킬·달리기 켜기)을 늘 띄웠는데 "PC 대비 버튼이 이상하게 많아 보인다" → 달리기 칩 빼고(조이스틱으로 충분), 누를 수 없는 아이템 칸(공격/방어)도 빼고, 칩은 상황 있을 때만.
- 과정: 방향키+QWER, 1~4 아이템 칸 등 여러 안을 거쳐 지금 구성으로 정착. 키가 많으면 불편하다는 피드백이 반복됨 → **상호작용은 E 하나로 몰기**.

## 11. 멀티플레이·서버

**목적**: 친구 방(초대 코드)과 봇 채우기로 같이 하기. 규칙 파일(`public/js/sim`)을 서버가 그대로 돌림.

**규칙**
1. 방장이 시작. 중간에 나가면 봇이 이어받음. 끝나면 8초 뒤 대기실.
2. 한 판은 20명이고 남는 자리는 봇.
3. **사람이 다 탈락하면 바로 끝 (2026-10-27)**: 사람이 전원 탈락(또는 나감)하면 봇끼리 끝날 때까지 안 기다리고 끝난 판처럼 8초 뒤 대기실. 플레이 기록도 그 시점에 남김.
4. 같이 하기는 보통 난이도 고정.

**수치**

| 항목 | 값 | 비고 |
|---|---|---|
| 방 정원 | 10명 | 2026-10-27에 20 → 10으로 축소. 처음엔 8 → 20 |
| 스냅샷 | 초당 약 10회 | 간격 최대 ~180ms는 1명일 때와 같음 (타이머 단위) |
| 입력 | 최대 초당 15번 | Cloudflare가 들어오는 메시지마다 요청으로 셈. 20명 방은 한 판에 대략 수천 요청 (무료 플랜 하루 한도 주의) |
| 서버 CPU | 한 판에 코어 4% 정도 | 로컬, 20명 소켓 측정 |
| 한 사람 받는 양 | 약 95 → 70KB/s | 공용 상태 JSON을 한 번만 만들고, 이름·색·옷·업무 위치 같은 안 바뀌는 값은 1초에 한 번(새 업무는 처음 1초 동안)만 |
| 보간 `INTERP` | 0.15~0.4초 자동 조절 | 스냅샷 도착 간격 + 흔들림×3, 늘 땐 빨리·줄 땐 천천히. 늦은 패킷은 0.25초까지 같은 방향으로 이어 그림 (`client/05-net.js`) |
| 수색조 비율 (온라인) | 40% | 4장 |
